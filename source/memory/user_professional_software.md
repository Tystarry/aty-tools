用户日常使用以下专业软件：
- Maya（三维建模与动画软件）
- UE / Unreal Engine（虚幻引擎）
- Nuke（节点式合成软件）
- PS / Photoshop（图像处理软件）

**规则：** 对话中涉及专业英文名词时，需在英文名词后的括号里添加中文注释，例如：vertex（顶点）、shader（着色器）、rigging（骨骼绑定）等。

**适用场景：** 所有涉及CG、游戏开发、影视后期等专业领域的对话。
