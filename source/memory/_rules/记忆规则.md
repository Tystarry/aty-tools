## 记录流程

**每次写完功能性脚本/插件/App/修完Bug后，必须先问：**

> "这个功能后续是否还会有修改？"

用户选择：
| 选项 | 含义 |
|------|------|
| **成功** | 功能完成、已验证可用、暂无修改计划 |
| **暂时没有** | 功能不完整、待继续开发、或后续可能需要修改 |
| **失败 / 暂不需要** | 需求取消、暂时不需要、或當時沒做成 |

## 分类管理规范

### 目录结构
```
memory/
├── MEMORY.md                  ← 总索引（树形）
├── _rules/
│   └── 记忆规则.md             ← 本文件
├── {软件名}/                   ← nuke / maya / ue / ...（自动添加）
│   └── {子标签}/               ← 通用 / arnold / redshift / vray / ...
│       ├── 成功/
│       │   └── {功能名}.md     ← 每个功能独立文件
│       ├── 暂时没有/
│       │   └── _追踪表.md      ← 统一表格
│       └── 失败/
│           └── _追踪表.md      ← 统一表格
```

### 成功项
- 每个功能/App **单独**一个 .md 记忆文件
- 必须包含：功能描述、文件路径、用法、依赖
- 生成 **zip 压缩包** 放到 `packages/` 目录
- zip 内含：插件脚本 + **功能说明文档.txt**（含安装方法）

### 暂时没有 / 失败
- 用 **统一表格**（`_追踪表.md`）管理
- 表头：`| 序号 | 名称 | 功能简述 | 当前进度 | 待完善/原因 | 最后更新 |`
- 如果我要继续修改：能从表中快速回顾之前的信息

### 2. 部署到线上（优先）
- 注意：本机 `python` 命令是 WindowsApps 死桩（静默无输出），一律用 `"C:/Program Files/Autodesk/Maya2024/bin/mayapy"` 代替
- 生成器输出到 `packages/插件面板.html`，部署前 `cp 插件面板.html index.html`
- **GitHub Pages (Lite):** 生成 `--lite` → cp → `mayapy _deploy_gh.py` → **https://tystarry.github.io/aty-tools/**
- **Vercel (完整+留言板):** 生成 `--vercel` → cp → `npx vercel@56.5.0 build --prod --yes` 然后 `npx vercel@56.5.0 deploy --prebuilt --prod --yes` → **https://packages-puce.vercel.app**（会自动 alias；如没更新再手动 `alias set`）
  - 必须用 prebuilt 模式，否则静态文件可能不更新
- 本地完整版: 生成（无参数）→ cp index.html
- 本机网络对 `*.vercel.app` 存在 DNS 污染（解析到 Facebook IP，curl 连不上）；部署本身走 api.vercel.com 正常，用 `npx vercel@56.5.0 inspect <url>` 验证部署状态，访问网站需用户走代理
- ⚠️ GitHub Pages（Jekyll 构建）不服务文件名以 `_` 开头或含 `#()` 等特殊字符的文件（404）；上传时 `safeName()` 自动删掉这些字符；中文目录/文件名可以正常服务
- 参考图上传统一改名为 `img_时间戳36进制_序号.ext`（纯字母+数字），现有图片已全部重命名为 `img_NNNN.png`；旋转功能：先 CSS 实时预览旋转，点「💾 保存旋转」才写回文件+更新索引 rot_ts（图墙用 ?v= 破缓存）
- 参考图去重：上传时浏览器算 SHA-256 存条目 `hash` 字段，与已有图片对比，重复自动跳过并提示；服务端 `_dedupe_refs.py` 补指纹/清存量重复；删除按钮在图墙卡片悬停右上角 + 查看器底部（红色 🗑，调 delAsset）；上传后有本地模糊占位图（localStorage `aty_ph_路径`）立即显示，真实图加载后淡入
- ⚠️ 本机 Windows 系统代理指向 127.0.0.1:17891（用户代理软件，时开时关）：mayapy 的 urllib 会读注册表代理，软件关闭时全部请求 ENOENT 失败；所有脚本必须 `urllib.request.install_opener(build_opener(ProxyHandler({})))` 绕过（直连 GitHub 可用）
- ⚠️ raw.githubusercontent.com 有 CDN 缓存，读索引必须走 GitHub API（`contents/assets_index.json` 返回 base64 content）；生成器 `_fetch_remote_index()` 和 JS `fetchIndex()` 都已改走 API；Vercel 的 api/assets 代理 raw 只读展示用途可接受

### 关键坑
- 生成器嵌入数据（`window.__EMBED_LOG__`）必须定义在主 script 内、`var DATA=` 之前，不能插在 data-store script 标签内部（会破坏 HTML）
- bat 文件不要含中文注释（UTF-8/GBK 编码在别的电脑会炸），中文逻辑放 ps1 文件（UTF-8 BOM）
- 打包 zip 时注意 Compress-Archive 的相对路径，zip 统一放 packages/
